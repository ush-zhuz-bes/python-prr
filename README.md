# Python: Жолдар мен тізімдер — интерактивті сабақ сайты

Екі 50 минуттық сабаққа арналған офлайн сайт: **1-сабақ — Жолдар (strings)**, **2-сабақ — Тізімдер (lists)**.
Мазмұны `Zholdar_tizimder_eki_sabak.docx` құжатына негізделген. Таза HTML5 + CSS3 + JavaScript:
CDN, сервер, `fetch`, модуль, құрастыру қадамы **жоқ**.

Сайт толықтай студентке арналған: оқытушыға арналған ақпарат, сабақ жоспары/таймері және дайын шешімдер
жоқ. Студент сабақты таңдайды да, бірден анықтамадан бастайды.

## Қалай іске қосу

1. Қалтаны ашыңыз.
2. `index.html` файлын екі рет басыңыз (Chrome, Edge, Firefox, Safari — соңғы нұсқалар).
3. Интернет қажет емес.

Телефонда: файлдарды бірге сақтап, `index.html` ашыңыз немесе қалтаны кез келген статикалық хостингке жүктеңіз.

## Файлдар

| Файл | Мақсаты |
|---|---|
| `index.html` | Беттің қаңқасы |
| `styles.css` | Дизайн: ашық (әдепкі) және қараңғы тақырып, басып шығару (A4) |
| `lessons.js` | Барлық сабақ деректері (`window.LESSONS`): анықтамалар, мысалдар, сұрақтар, 16 нұсқа × 5 тапсырма = 80 практикалық тапсырма, 16 үй жұмысы |
| `app.js` | Барлық логика: слайдтар, зертханалар, нұсқа таңдау, прогресс, басып шығару |
| `tools/` | Қосымша (сайтқа керек емес): `lessons.js`-ты қайта жасайтын Python скрипттері, бастапқы `.docx` және `tools/homework.py` (үй жұмысы мәтіндері) |

## Сабақ құрылымы (екі сабақта да бірдей, 6 бөлім)

1. Түсіндіру: анықтамалар, амалдар, интерактив зертханалар — сабақты таңдағаннан кейін бірден осыдан басталады
2. Үш практикалық мысал (қадамдық демонстрация, оңай түсінуге бейімделген)
3. Бекіту сұрақтары (6 карточка)
4. Практикалық жұмыс: 8 нұсқа (әрқайсысында 5 тапсырма, **шешімі көрсетілмейді**)
5. Үй жұмысы: практикада таңдалған нұсқаға автоматты түрде сәйкес келетін, сәл күрделірек, жаңа жағдаятпен берілген 3 қадамды тапсырма (**шешімі/коды көрсетілмейді**)
6. Қорытынды және өзін-өзі бағалау

**Интерактивтер.** 1-сабақ: индекстер зертханасы (оң/теріс индекс, шектен шығу қатесі), тілімдеу зертханасы (`start/stop/step`, бос мәндер, теріс қадам, `step=0` қатесі), әдістер (`strip`, `lower`, `upper`, `replace`, `find`, `count`), өзгермейтіндік демонстрациясы.
2-сабақ: тізім зертханасы (`append`, `insert`, `remove`, `pop`, `items[i] = …`, `sort`, `reverse`, `items = items.sort()` қатесі; бастапқы күй → команда → соңғы күй → қайтарған мән; қателер қазақша түсіндіріледі), `b = a` және `b = a.copy()` көшіру демонстрациясы, `split()` + `int()` демонстрациясы.

## Нұсқа таңдау

«Практика» бөлімінде студент өз нұсқасын (1–8) қолмен таңдайды немесе «Кездейсоқ нұсқа» батырмасын басады;
нұсқаға тікелей сілтеме (`#l=lists&s=v-data&v=5`), тапсырма мәтінін және бастапқы деректерді көшіру,
тапсырмаларды «орындалды» деп белгілеу мүмкіндіктері бар. Таңдалған нұсқа «Үй жұмысы» бөлімінде
автоматты түрде сәйкес тапсырманы ашады.

**Басып шығару**: практикалық нұсқа мен үй жұмысы бөлек басылады (A4, ақ фон, студент аты/тобы/күні жолдары).
Басқа ештеңе (навигация, батырмалар) басылмайды.

## Сақталатын деректер

Прогресс, тақырып, қаріп өлшемі `localStorage`-та сақталады (кілттер: `pylessons.settings.v1`, `pylessons.progress.v1`). `localStorage` өшірілген болса, сайт жұмысын жалғастырады (деректер тек ашық бет ішінде сақталады). «Прогресті тазалау» алдымен растау сұрайды.

## Маңызды ескертпелер (адал нота)

- **«Қадамдық демонстрация» — Python интерпретаторы емес.** Мысалдардағы қадамдар мен айнымалы мәндері алдын ала дайындалған: код нағыз CPython-да орындалып, нәтижелері құжаттағы нәтижелермен автоматты түрде салыстырылған (сәйкес келмесе, құрастыру тоқтайды). Зертханалар (индекс, тілімдеу, әдістер, тізім операциялары) Python ережелерін JavaScript-те қайталайды; әртүрлі кездейсоқ сынақтарда нағыз Python-мен салыстырылды, бірақ олар Python-ның толық көшірмесі емес.
- **Практика мен үй жұмысының дайын шешімі сайтта жоқ.** Интерфейсте шешім көрсету мүмкіндігі жоқ — студент тапсырманы өзі орындайды.
- Бұл статикалық сайт: баптаулары мен деректері ашық, құпия сынақ үшін қолданбаңыз.
- Бекіту сұрақтарындағы еркін мәтін жауаптары автоматты бағаланбайды: студент үлгі жауаппен салыстырып, «Түсіндім / Қайталау керек» деп өзін белгілейді.
- Бекіту сұрақтары, мысалдардың қадам түсініктемелері, үй жұмысы және қорытынды мәтіндері — құжаттағы мазмұнға сүйеніп жазылған қосымша дидактикалық мәтін; **80 тапсырманың мәтіні, мысал кодтары мен олардың нәтижелері құжаттан алынған**.

## Мазмұнды өзгерту / қайта жасау (міндетті емес)

`lessons.js` — қолмен өңдеуге болатын қарапайым JS нысаны. Сонымен қатар, `tools/` ішінде Python 3 арқылы қайта жасауға болады:

```
python3 tools/build.py      # tools/source.docx, tools/authored.py, tools/solutions.py, tools/homework.py → lessons.js
```

Мәтінді өзгерту: `tools/authored.py` (мысалдар, сұрақтар, қорытынды), `tools/solutions.py` (ішкі тексеру үшін ғана — сайтта көрсетілмейді), `tools/homework.py` (үй жұмысы). Сайтты қолдану үшін бұл қадам қажет емес.

## Қолжетімділік

Барлығы пернетақтамен басқарылады, фокус айқын көрінеді, түс контрасты жоғары, `prefers-reduced-motion` ескеріледі (анимациялар өшеді), мобильді көрініс көлденең айналусыз, код блоктары өз ішінде айналады. Фондық қозғалыс, дыбыс, жыпылықтау жоқ.
